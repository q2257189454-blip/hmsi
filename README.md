# HMSI Web 交互原型

美团商赛 HMSI 产品展示原型，使用原生 HTML/CSS/JS 实现。

## 页面结构

- 登录页
- 工作台总览
- 销售额预估
- 智能选址
- 点位对比
- 地推策略
- AI 报告

## 交互说明

- 登录页点击 `登录` 或 `进入演示环境` 进入系统。
- 左侧边栏可切换六个核心业务页面。
- AI 报告页点击 `生成报告` 会更新右侧 AI 助手回答。
